# Vaas

> Vaas is a Colombian fintech building debt infrastructure for Latin America — a platform that automates asset-backed debt facilities for originators, lenders, and debt providers, with autonomous asset verification, payment reconciliation, and real-time collateral ownership enforcement for private credit. Backed by Andreessen Horowitz (a16z).

Vaas ("public rails for private credit") verifies that financed assets exist (documents in, structured data out), reconciles every transfer to the rightful holder end to end, and enforces who owns what and when so assets can never be pledged twice. Customers include fintech originators, asset managers, and private equity debt providers; Addi is a named customer. Vaas does not currently publish a public developer portal, API documentation, or machine-readable API specifications.

## Product

- Documents: autonomous verification of asset documentation — evidence an asset is authentic, valid, and ready to move
- Cash flow: payment reconciliation with full traceability, delivered to the rightful holder
- Ownership: real-time enforcement of collateral rights so assets cannot be double-pledged
- Demos: [Waiver management](https://www.getvaas.com/en/demo/waivers), [Reconciliation event](https://www.getvaas.com/en/demo/reconciliation)
